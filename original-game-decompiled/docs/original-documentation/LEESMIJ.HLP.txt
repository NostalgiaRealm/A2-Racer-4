Deze melding kan zich in twee situaties voordoen:





A2 Racer cd zit niet in de cd-romspeler.

Als je A2 Racer wilt spelen, moet de cd in de cd-romspeler zitten vóórdat je het spel opstart.

A2 Racer moet in de master cd-romspeler zitten als je A2 Racer wilt spelen. Als je niet weet welk van je cd-romspelers de master is, probeer dan alle cd-romspelers, totdat A2 Racer werkt.

===== TOPIC 36: Error-...could not create surface (application out of free memory) =====


Error-...could not create surface (application out of free memory)



Deze melding kan twee verschillende oorzaken hebben. Het is mogelijk dat er sprake is van een probleem met 
Virtual Memory
. Ook kan het zijn dat je geen 
3D-kaart
 hebt geïnstalleerd, maar wel voor deze instelling hebt gekozen in het 
Opties
-menu. Hieronder zie je hoe je deze problemen kunt oplossen.





Virtual Memory



Windows maakt gebruik van Virtual Memory. Zodra A2 Racer wordt opgestart, wordt alles wat op dat moment in het geheugen van je pc staat naar Virtual Memory geschreven. Waarschijnlijk is de harde schijf waarop deze file gezet wordt vol (meestal C:\). Er moet minimaal 100 Mb vrij zijn om A2 Racer te kunnen draaien. Is dit niet het geval, dan kun je het beste proberen wat harde schijfruimte vrij te maken.




Je kunt via de volgende stappen controleren of er genoeg ruimte vrij is op de harde schijf:




1.
Dubbelklik op het pictogram 
Deze computer
 op het bureaublad.



2.
Selecteer de harde schijf. Dit is meestal C:\.



3.
Ga naar 
Bestand
 en kies 
Eigenschappen
 (of: klik op je rechter muisknop en kies 
Eigenschappen
).



4.
Hier kun je aflezen hoeveel ruimte er nog vrij is.



3D-kaart

Je hebt in het 
Opties
-menu gekozen voor 3D-kaart. Jouw 3D-kaart wordt niet goed ondersteund door DirectX, óf je hebt geen 3D-kaart in je systeem zitten (dit is een extra 'add-on' voor je pc). Zet in het 
Opties
-menu de 3D-kaart uit en zet de weergave op 
Normaal
. Start dan A2 Racer opnieuw.

# A2 Racer 4 v1.0.0 — port, decompile and desktop builds

A port of the Dutch racing game *A2 Racer 4 – De politie slaat terug!* (Davilex, 2000) to WebGL and Three.js, and the decompile it is built on. The race is the original code: `spel.dat` recompiled from x86 to WebAssembly, so its physics, AI, rules and HUD logic run as shipped. The menu is rewritten by hand from the original forms and code. Artwork, music, speech and text are the originals, in Dutch. Davilex's two official updates are in, and `3D kaart` off runs the 8-bit software path.

On 2026-11-03 the `.zip` copies of the packages and of the web build were removed from this release. They held the same files as the installer, the `.dmg` and the source. `SHA256SUMS.txt` was rewritten without them.

Download from [GitHub](https://github.com/NostalgiaRealm/A2-Racer-4/releases/tag/v1.0.0) or [GitLab](https://gitlab.com/Nostalgia_Realm/A2-Racer-4/-/releases/v1.0.0). [Changelog](../../CHANGELOG.md).

| Source of the port | `A2-Racer-4-1.0.0-source.tar.gz`: without the decompile. `npm ci`, `npm start` and `npm run build` work from it. Recompiling and making desktop icons need the repository, which has the decompile |
| Decompile | `A2-Racer-4-1.0.0-original-game-decompiled.tar.gz`, with `.manifest.json` (every file, size, SHA-256) and `.sha256` |
| Checksums and identity | `SHA256SUMS.txt`, `BUILD-INFO-1.0.0.json`, `CHANGELOG-1.0.0.md`, `integrity-*.json` |

The desktop builds are not code-signed: Windows SmartScreen warns, and macOS needs a right-click and Open on first start (ad-hoc signed, not notarized). The AppImage needs FUSE, or `--appimage-extract-and-run`.

## What was checked

Each row covers only what it says.

| Kind | Scope | Result |
|---|---|---|
| Against the original under Wine | Etappe 0, Amsterdam: speeds per movement state, reverse, brake, countdown, first time steps, three frames | Speeds within 2.05% at 1 s and 0.5% at 4 and 8 s |
| Against the original on emulated Windows 98 | 8-bit path, etappe 0, frames at rest, pixel by pixel | 88.1% of the picture identical at 640x480, 85.5% at 320x200 |
| Flow in a browser | Etappe 0, real clicks, a whole race by the bot to its results, headless Chromium | Pass |
| Performance | Etappe 0, bot route, 60 s, headless Chromium, RX 6700 XT, 800x360 at DPR 2, 8x CPU throttle | 60 FPS worst second |
| Package content | Linux and Windows packages, and macOS by the same step on GitHub Actions | Game files byte-identical to the web build: `integrity-*.json` |
| Web build and source archive | Web zip unpacked and served: a race by the bot for 15 s. Source archive unpacked, `npm ci`, `npm run build` | Pass, no console errors. Rebuilt web build byte-identical to the zip |
| Launch, Linux | Packaged app under Xvfb with a software GPU: menu's first screen, a race by the bot for 30 s; also the app from inside the AppImage | Pass, no console errors |
| Launch, Windows package under Wine | Under Wine on Linux, not on Windows: menu's first screen, a race by the bot for 20 s | Pass, no console errors |
| Source | Fresh clone of the tag: `rcs.img` restored, `spel.wasm` recompiled, web build rebuilt | `spel.wasm` and every file of the web build byte-identical to this release |

Performance measured on a desktop GPU with CPU throttling does not predict a real phone.

## Not checked

- The Windows package has not been started on Windows, and the macOS packages have not been started at all. They contain the same game files and the same wrapper as the Linux package.
- A race played through on any package. The whole race by the bot ran in a browser.
- Sound by ear. It was checked by state only.
- Real phones and tablets, real gamepads, joysticks and wheels, Firefox, Safari, hardware of the period.
- Levels other than Amsterdam beyond a boot, and the Country etappe with the truck beyond one launch. Chase, highway, Supercop and the Tour played through.
- Steering, turbo, damage, collisions, race end and traffic against the original. The original has not been run with the updates.

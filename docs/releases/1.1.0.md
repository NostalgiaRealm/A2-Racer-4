# A2 Racer 4 v1.1.0 — the owner's fixes in the race

The race now runs the fixes from the Windows patch `A2-Racer-4-Fixes` 1.5.4 that still mattered in the browser. The port runs the race at 60 ticks per second, where the original game has bugs that the patch fixes: cars that hang on a ramp, cars that climb an invisible slope, a reset that can stop the game, and effects that count per frame what they mean per second. These parts of the patch are its own machine code, lifted to WebAssembly together with `spel.dat`, so the race does what the patched game does.

Download from [GitHub](https://github.com/NostalgiaRealm/A2-Racer-4/releases/tag/v1.1.0) or [GitLab](https://gitlab.com/Nostalgia_Realm/A2-Racer-4/-/releases/v1.1.0), or play at <https://games.nostalgiarealm.com/a2racer4/>. [Changelog](../../CHANGELOG.md).

## Changes since 1.0.0

| Part of the patch | What changes in the race |
|---|---|
| 11, hung cars | A car that stands still for 3 s with an axle off the ground, or tipped over, goes back on the road. Racers no longer stay stuck until the race ends |
| 12, contacts | A car no longer pulls its front up out of nowhere and stops: contacts end when they leave their triangle |
| 12, the reset | No `Illegal chunk` at the last section. A reset lands on the road on etappes 5, 6 and 7. Lanes are freed, and a racer's reset no longer blocks your Enter key |
| 13, frame rate | The police brake properly, the camera lags as at 25 FPS, cars reach the light of the road, skid marks last about 2 s, smoke lasts longer, mud and water leave room for sparks, pickups and animations step at their own pace |

Not taken from the patch, as the browser port does these its own way or never meets them: resolution and HUD, texture memory, transparency, Z-buffer, 32-bit colour, the clock, long uptime, the launcher, and fixes that matter only above 66 or 300 frames per second. The list with reasons: `tools/recomp/owner-fixes/README.md`.

Saves, settings and the menu are unchanged.

## What was checked

Each row covers only what it says.

| Kind | Scope | Result |
|---|---|---|
| Patch bytes | His `spel_patch.asm` assembled with nasm against the bytes in his patcher | Identical |
| Whole races, headless | The bot on all 10 etappes, with and without the fixes | No error on either. With them the 25 Hz tick runs on every etappe and 6 stuck cars were put back; without them none |
| Against the original under Wine | Launch speeds at 1, 4 and 8 s | Unchanged from 1.0.0, so the comparison with the original still holds |
| Flow in a browser | Etappe 0, real clicks, a whole race by the bot to its results, on both the 3D and the 8-bit path; race UI 76 checks; phone flow 7 | Pass, no console errors |
| Repeat trace | Same race at normal speed and at 8x CPU throttle | All 485 physics bodies equal for 71 s |
| Performance | Etappe 0, 8x CPU throttle, alternating with 1.0.0's race code on the same machine | About 0.8 ms more per tick. That machine was busy: 1.0.0's code also dropped to 45 to 59 FPS in its worst second there |
| Package content | Linux and Windows packages here, macOS on GitHub Actions | Game files byte-identical to the web build: `integrity-*.json` |
| Launch, Linux | Packaged app under Xvfb with a software GPU: menu's first screen, a race by the bot for 30 s | Pass, no console errors |
| Live site | <https://games.nostalgiarealm.com/a2racer4/> after the upload | See the hosting check in the validation document |

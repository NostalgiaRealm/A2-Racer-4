# A2 Racer 4 v1.1.1 — the original icon

The browser tab now shows the game's own icon: the icon of `A2Racer4.exe`, 32x32 in 256 colours, as an icon file made from the resource's own bytes without conversion. It is `favicon.ico` in the web build, and every desktop build carries it. The desktop apps already used the same icon. The race and the menu are unchanged from [1.1.0](1.1.0.md), which brought the owner's fixes into the race.

Download from [GitHub](https://github.com/NostalgiaRealm/A2-Racer-4/releases/tag/v1.1.1) or [GitLab](https://gitlab.com/Nostalgia_Realm/A2-Racer-4/-/releases/v1.1.1), or play at <https://games.nostalgiarealm.com/a2racer4/>. [Changelog](../../CHANGELOG.md).

# A2 Racer 4 v1.1.3 — the wheels

The wheels of the cars no longer pulse. The browser port draws the picture between the last two game ticks so it runs smoothly at any display rate. Wheels at speed turn about 60 degrees per tick, and drawing them halfway between two such poses made them shrink and skew, by up to a third, every tick. Now a wheel keeps the turn the game gave it in the latest tick and only its position follows the car smoothly, so it always has its own size and shape, as on Windows and under Wine. Together with [1.1.2](1.1.2.md), which fixed the player's shadow, the car now looks as steady as in the original.
